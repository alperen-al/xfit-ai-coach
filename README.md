# XFIT – AI Fitness & Diet Coach (Prototype)

Single-page prototype that takes a user's profile and body measurements and generates a personalised training and nutrition plan as structured tables.

Tech: HTML · CSS · JavaScript. Open `index.html` in a browser.

By **Alperen Korkut** · [korkut-dev.vercel.app](https://korkut-dev.vercel.app)

## Setup
On first use the page asks for your own Groq API key and stores it only in your browser (localStorage). No key is included in this repository.
